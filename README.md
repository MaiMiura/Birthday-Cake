# Birthday Cake 🎂

誕生日の友だちに贈る、ろうそくを吹き消す Web アプリです。

**息を吹く → 火が消える → お祝いが出る** の流れで遊べます。

ケーキは **いちご** と **チョコ** の 2 種類から選べます。

1. ケーキと「願いごとをして、ふーっと吹いてね」の一言だけが表示されます
2. マイクに向かって息を吹くと、炎がゆらいで少しずつ小さくなり、消えていきます
3. 全部消えると部屋がふっと暗くなり、明かりがついて紙吹雪と一緒に名前・お祝いメッセージが現れます（オルゴールの Happy Birthday つき）

マイクが使えないときや許可されなかったときは、**ケーキをタップ**するといちばん近いろうそくが消えます。マイクが使えるときも、しばらくすると「タップしても消せるよ」と案内が出ます。

## 使い方

ビルド不要の静的サイトです。`index.html` をそのまま公開すれば動きます。

### リンクを作る

`create.html` を開くと、名前・メッセージ・ケーキの種類を選んで贈るリンクを作れます。

URL パラメータを直接書くこともできます。

| パラメータ | 内容 | 例 |
| --- | --- | --- |
| `name` | 友だちの名前 | `name=はなこ` |
| `msg` | お祝いメッセージ（改行は `%0A`）。省略時は定型文 | `msg=いつもありがとう！` |
| `theme` | ケーキの種類。`strawberry`（いちご・既定）または `chocolate`（チョコ） | `theme=chocolate` |

例: `https://<ユーザー名>.github.io/Birthday-Cake/?name=はなこ&theme=chocolate`

### 公開する

マイクは **HTTPS**（または `localhost`）でしか使えません。GitHub Pages なら、リポジトリの Settings → Pages で公開ブランチを選ぶだけで HTTPS で配信されます。

手元で試すとき:

```sh
python3 -m http.server 8000
# http://localhost:8000/?name=はなこ を開く
```

## ケーキの写真について

`assets/` のケーキ写真は、文字の部分を切り取り、炎を消して加工したものです。炎・煙・文字はアプリ側で上に重ねて描いているので、1 本ずつ吹き消せます。ろうそくの位置は `app.js` の `THEMES` に写真のピクセル座標で書いてあります。

## 息の判定について

周りの音にも反応しうるので、厳密さより「気持ちよく遊べること」を優先しています。

- 最初の 0.6 秒で部屋の静かさを覚え、それより十分大きい音が続いたときを「吹いている」とみなします
- 一瞬の物音では消えません。炎ごとに体力があり、吹き続けると減って、やめると少しずつ戻ります
- 強く吹けば 0.3〜0.5 秒、そこそこの強さでも 1 秒ほどで消えます。ろうそくごとに少しずつ強さが違うので、順番にふっと消えていきます
- 息の音を消されないよう、ブラウザのノイズ抑制・自動ゲイン調整はオフにしています

感度は `app.js` の `BLOW_RATE` / `RECOVER_RATE` と、`readBlow()` 内のしきい値で調整できます。
